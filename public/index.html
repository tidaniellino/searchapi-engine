Segurança Privada por Chave Mestra

      

        Esta API é de acesso restrito. Qualquer requisição sem a sua Chave Mestra será rejeitada com 401 Unauthorized. Você pode enviar a chave via parâmetro ?api_key=SUA_CHAVE ou no cabeçalho Authorization: Bearer SUA_CHAVE.
      


      

        curl "http://localhost:3000/api/v1/search?engine=google&q=inteligencia+artificial&api_key=sk_private_master_daniel_2026"
