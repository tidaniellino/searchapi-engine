      API Reference & Quickstart
    


    

      
Authentication & Endpoint

      

        All API requests are sent via HTTP GET to /api/v1/search. Authenticate by providing your API key either as a query parameter (?api_key=sk_live_...) or in the HTTP Authorization header (Authorization: Bearer sk_live_...).
      


      

        curl "http://localhost:3000/api/v1/search?engine=google&q=coffee+shops+in+austin&api_key=sk_live_demo1234567890abcdef"
